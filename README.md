# MULTI-MODEL ROUTER (need to work on the name)


## About
- A middle ware bettween your app and remote llm providers allowing you to use llm without bothering about choosing which one. So no more is it too small, is it too big etc etc, which would be better Qwen or Kimi. 

## Features 
- NLP model to classify the prompt based on it's complexity and task
- FastAPI endpoint for the model.
- GO back-end for the rest of the logic for maximum speed 
- React + TS front-end for maximum pretty :sparkle:
